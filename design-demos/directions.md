# 六个候选方向

三个完整版统一1440×900，均保留三栏。

## A 清晰工作台（入选，dir-1.html）
最佳设计师方法：Naoto Fukasawa 的低负担日常工具思路，非本人作品。
借用：低对比表面区分、主要操作黑白、小面积语义色；不靠大标题。
素材：真实黑白标志、真实榫灵、工具调用与文件树。
骨架：宽工作区侧栏 / 宽对话 / 紧凑竖向工具 dock。对话首先被看见。
胆量：克制到让审批成为唯一高权重动作区。
form 来自：Agent 工作过程中，用户需要先读清楚，再作决定。
五问：操作主场 / 桌面近距 / 清冷明亮 / 中等密度 / 工具证据。

## B 深色工程台（入选，dir-2.html）
现实参照：Panic Nova 主窗口，官方出处见 product-facts.md，参考板 refs/board.jpg。
借用：深色分区、可压缩导航、明确分隔的文件检查区；不复制其品牌。
素材：真实反白标志、真实榫灵、带行号的只读代码预览。
骨架：窄项目会话栏 / 对话 / 加宽的代码与文件检查栏，右栏横向 tabs。
胆量：右栏足够大，让文件检查与对话同等重要，仍保留会话中心。
form 来自：开发者审批读文件时，需要直接看到路径、权限和代码证据。
五问：检查主场 / 桌面近距 / 暗色专注 / 较高密度 / 文件证据。

## C 留白伴行（入选，dir-3.html）
最佳设计师方法：Jasper Morrison 的 Super Normal 工具感，非本人作品。
借用：浅雾绿表面、圆润适量的组件、清晰非衬线中文；禁止奶油衬线套路。
素材：榫灵在独立陪伴区、计划步骤数据可视化、真实标志。
骨架：分组侧栏 / 较窄的居中对话阅读列 / 计划优先的上下分区 inspector。
胆量：计划与陪伴组成右栏层次；不让宠物抢走审批的注意。
form 来自：长时 Agent 协作既要看清进度，也要让等待平静。
五问：协作主场 / 桌面近距 / 温和清新 / 较疏密度 / 进度与陪伴。

## D 面板聚焦（备选）
现实参照：Zed 官方工作区文档，refs/board.jpg。
借用紧凑面板与窄间距，黑白色、中间对话为完整工作区；右栏折叠为图标后聚焦阅读。
素材为完整会话与停靠 tabs；骨架是三栏可折叠。胆量在极简 chrome。
form 来自对话和文件随时切换，五问：阅读 / 近距 / 中性 / 密 / 面板。

## E 终端软未来（备选）
秒数轮盘：取样秒数35；web有20项，35%20+1=16，已亲眼查看16-terminal-core.jpg。
借用暗底、等宽工具证据、柔绿色状态；不借用样张中的紫色渐变。
主角为工具参数与结果，骨架：侧栏/消息事件流/上下文 inspector；胆量在等宽记录。
form 来自工具的结构化输出，五问：证据 / 近距 / 冷 / 密 / 事件。

## F 高密度检视（备选）
秒数轮盘：east有12项，35%12+1=12，已亲眼查看12-japan-magazine-dense.jpg。
借用网格密度与清楚的分区，缩减杂志式巨字，仅黄黑用于选中态。
主角为计划与文件矩阵；骨架：侧栏/对话/表格状 inspector；胆量在紧凑网格。
form 来自一次任务的证据并置，五问：检视 / 近距 / 明快 / 高 / 网格。
