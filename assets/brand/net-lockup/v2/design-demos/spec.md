# 大写 DOUGONG 新设计探索

用户最新原话：“开始设计这个大写，不要受现在这个约束”。此要求解除对现有V2字形的延续约束，重新探索大写字标。
沿用已明确的交付形式：合构图标 + DOUGONG + NET。DOUGONG必须全大写，字母次序D O U G O N G，两个O和两个G分别一致。重点设计字标，不以更换背景或普通字体代替字形探索。
现有图标、NET和黑白品牌关系作为比较基准；可自由调整大小、光学间距和对齐，不受当前字重、圆角、宽度、切角约束。

输出统一1440×900完整设计方向板，每版含浅色主组合、反白组合与桌面标题栏缩小样。原图标使用真实SVG，不由生图工具重新生成；字标图像为概念探索，不能冒充最终矢量。
三个单文件HTML与PNG、六候选缩略图总览。先展示真实方向，选择后才制作完整矢量套件。
素材档位T0+T1：真实SVG图标、代码组合、imagegen字标概念。保留当前V2正式文件；本轮在其design-demos子目录内工作。

form五问：品牌识别主标；桌面近距和大屏展示；每方向不同温度；七字母与两侧辅助元素；从“承托、构造、协作”产生字形结构。

来源：现有项目品牌、用户多轮原话、用户提供的dsh组合参考。外部品牌仅作为内部字形语言研究，不出现在DOUGONG成品中。
